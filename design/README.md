# 知更 Android 0.6 设计

Figma：https://www.figma.com/design/U1wIxILbo1lK05eGDY9eo8?node-id=6-653

三个可编辑画板：国内发现、推荐榜单、图书下载。使用 Noto Sans SC 对应安卓中文无衬线字体；暖白 #F7F5EF、墨绿 #244E40、朱砂 #BB614E，间距与圆角见 zhigeng-theme.json。主组件包含作品卡片、榜单行、分类标签；下载按钮基于 Material 3。

175 个后代图层由可编辑文字、布局框架与组件实例构成，未使用整屏截图替代设计。内置编辑推荐采用原创文字封面；在线接口提供封面时动态展示真实封面。

榜单默认采用公开说明的编辑推荐顺序，影视可切换 TMDB 用户评分榜，不伪造豆瓣榜或实时热度。下载卡片在获取真实链接前显示占位说明，真实链接仅显示在用户本次会话界面中。

## 0.6.1 · AI 助手

新增可编辑的[助手首页](https://www.figma.com/design/U1wIxILbo1lK05eGDY9eo8?node-id=13-41)。29 个后代图层：6 个布局框架、19 个文字、4 个组件实例，无图片填充。复用品牌变量与 Material 3 按钮，新增带文字属性的助手问题卡片组件；全部文字使用 Noto Sans SC。官方聊天网站在 App 中嵌入，本画板设计范围是知更的助手首页。
