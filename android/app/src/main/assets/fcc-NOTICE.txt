Zhigeng uses an independently written Android network client of FCC's public model-list and Anthropic Messages APIs. The Python FCC runtime is not included in this APK. Provider names, identifiers and official credential links in fcc-providers.json are a dated factual directory, not a list of unlocked models or promised free quotas.
FCC remains an independent open-source project, not an Anthropic endorsement. Providers control accounts, model availability, billing and limits.
