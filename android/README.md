# 知更 Android 0.6.6

独立原生安卓应用（Java + Android SDK），不是 WebView 网页壳，不依赖前一版知更网站或 ChatGPT 网页登录。

- 安卓 8.0 及以上；通用 APK，不捆绑原生架构库。
- 发现：电影、电视剧、动漫、综艺、书籍，按年份搜索与筛选；影视口碑排序。
- 阅读：公开目录搜书，以及适配自 heartleo/zlib（MIT）的账号登录、EAPI 搜索、年份范围、语言、格式、精确检索和翻页。图书详情内获取下载链接、复制、下载进度、取消，完成后加入书架；链接与下载权限取决于账号及源站。账号登录失败时尝试上游 RPC 登录方式。
- 书架：想读、在读、已读，收藏保存在本设备。长按移除。
- 本地图书：系统文件选择器导入 TXT / EPUB / PDF；TXT 和 EPUB 使用 Readium 在 App 内阅读，保存内容定位与多个书签；PDF 在 App 内使用 Android PDF 渲染器阅读。EPUB 保留章节、图片与书内链接；可切换原书排版，不支持 DRM 加密文件。
- 设置：TMDB 凭证测试、Z-Library 账号连接与清除。凭证和会话由 Android Keystore 的 AES-GCM 密钥加密；不保存密码，不写入仓库或日志。关闭系统备份，卸载会清除本机配置与阅读记录。

影视搜索需要有效 TMDB 凭证。书籍与动漫无需 TMDB。各来源可能受网络、限流、账号或源站可用性影响；Z-Library 的实时账号连接需用户自己的账号验证。

## 构建

JDK 17 / Gradle 8.9 / Android SDK 35 / AGP 8.7.3：

```bash
python3 -m pip install fonttools==4.59.0 brotli==1.1.0
python3 scripts/prepare-reader-font.py
cd android
gradle :app:assembleRelease
```

仓库 Actions 的 `Build Zhigeng Android APK` 自动构建未签名 APK。最终交付 APK 使用单独保管的私有发布密钥签名；私钥不放公开仓库。后续更新必须沿用同一签名。

`app/src/main/assets/heartleo-zlib-MIT.txt` 保留上游许可。内置目录来自仓库已有真实数据快照，不以快照伪装实时结果。

## 0.6.1 · Duck.ai 助手

- 每个主页面右上角「AI 助手」进入原生助手首页，沿用现有 Figma 品牌色与圆角。
- 内置 Duck.ai 官方网页，提供加载进度、刷新、错误重试及应用内返回。其他 HTTPS 来源继续在应用内资料页打开，不调用外部浏览器。未连接非公开聊天 API，不代用户发送消息或接受服务条款。
- 三个中文问题模板需用户点击复制，再粘贴到官方聊天框发送。不会自动读取或上传书架、阅读记录和账号凭证。
- 网页自身管理模型、用量和历史记录；本次支持文字聊天，未申请麦克风和相机权限。首次使用需在官方页面完成服务提示。可用性受网络、Android System WebView 和服务状态影响。
- 导航策略 JVM 检查拒绝 HTTP、伪冒域名、用户信息 URL、非标准端口和本地协议。模拟器验证页面打开与应用内返回；不自动发送真实对话。

## 0.6.2 · FCC 多模型

- AI 助手增加 FCC 入口。原生连接页、聊天页和可搜索服务商目录，不打开外部浏览器。
- 对接 Free Claude Code 的 `/v1/models?view=messages` 与 `/v1/messages`，使用可选 Bearer Proxy Token、Anthropic Messages 文本请求及 SSE 增量响应。没有复制 FCC Python 运行时，也没有在手机上运行编程代理。
- 模型列表来自用户网关；目录不可用时可手动填写模型 ID。61 家服务商仅为上游目录快照（2026-10-17，源提交 c5239619be489ff393fff29caf838c8a5a957454），不代表均已开通或免费。服务商密钥由用户在 FCC 管理端配置。
- 本机网关 Token、连接、模型缓存和当前对话由 Android Keystore 加密。仅发送当前对话最近 12 轮（并限制字符总量），不附带书架或图书账号。新建对话会清除该网关的本机当前记录。
- 支持停止、错误后保留问题草稿、复制回复；失败/取消的回复不加入后续上下文。鉴权、额度、限流、超时分别提示；不会自动重发失败问题。FCC 管理端配置的跨模型路由由 FCC 执行。
- 需要可从手机访问的用户自有 HTTPS FCC 网关。本项目不提供公共网关、账号、API Key 或任何保证的免费额度。FCC 默认本地管理端应继续保留本机访问；手机只需访问代理接口。
- 测试包括 JVM 的模型目录、上下文裁剪、SSE、取消、错误和 URL 策略；模拟器使用明确标注的本地 HTTPS 协议测试服务验证流程，不将测试回复当作真实 AI。测试 CA 和启动快捷方式仅在 debug 变体存在，release 检查排除它们。
- 上游项目与许可见 `app/src/main/assets/fcc-NOTICE.txt`。真实 FCC 网关及真实服务商对话尚需用户自己的地址和凭证验证。

## 0.6.3 · 聊天体验优化

- 未发送的草稿加密保存在本机；切换模型、标签页或重新打开应用可恢复。请求失败或停止后保留原问题，成功后清空草稿，不自动重发。
- 模型按钮及回复标题显示目录中的可读名称。首次发送会移除欢迎卡片；流式刷新合并为短间隔更新，浏览上文时暂停自动滚动，点击状态文字可跟随最新回复。
- 对话、模型缓存和草稿按网关地址与 Proxy Token 分别保存；更换 Token 不会看到前一凭证的记录。旧版当前连接的记录自动迁移，沿用原有 Keystore 加密。Token 轮换后旧记录仍属于原凭证；如需继续查看，请重新使用原连接。
- 新增模拟器检查：切换模型与标签页保留草稿、进程重启恢复、首次发送移除欢迎卡、429 保留草稿与重试、慢速回复停止。所有回复仍为标注清楚的本地协议测试，真实服务需用户网关。

## 0.6.4 · 安静的阅读页

- 接入 Readium Kotlin 3.1.0（BSD-3-Clause）；EPUB 使用真实章节文档、图片、链接和内容定位，不再抽取为整本纯文本。TXT 在本机识别 UTF-8 / GB18030、识别常见章节标题并转换为临时 EPUB，共用排版、目录、书签与位置恢复。转换文件留在应用缓存；不上传图书。
- 默认隐藏工具栏。点击中央唤出顶部返回与添加书签、底部目录/多书签/进度/排版；左右边缘轻点或左右滑动可翻页，也可选择滚动。书签长按可删除。
- 离线中文宋体来自 Noto Serif SC，按固定上游提交生成 400 字重 WOFF2，保留常用拉丁字符、标点及 CJK 基本区/扩展 A 字形，其余字形使用系统回退字体。另可选择系统黑体；支持纸白、米色、夜间主题及字号、行距、页边距、段距。
- 开启「使用原书排版」后部分间距受原书样式控制。PDF 沿用 Android PdfRenderer，改为可收起的页码、进度和书签面板；不对 PDF 重排正文。
- 新版按 Readium Locator 保存位置，调字号后按内容恢复。旧版 EPUB/TXT 的像素进度与旧书签无法精确迁移，首次升级需从目录定位一次；旧数据不会被删除。PDF 页码沿用原有数据。
- 默认字体衍生文件由构建脚本生成并改名，上游版本与 git blob 在脚本中固定并校验。Readium 与字体许可完整保留在应用 assets。
- Figma 阅读设计：https://www.figma.com/design/U1wIxILbo1lK05eGDY9eo8?node-id=20-134 。界面参考 Anx Reader 的简洁阅读方向，没有复制其 Flutter 代码。
- 本地自写测试文档仅打入 debug：验证 EPUB 图片/章节、目录、书签、主题、重启定位，TXT/GB18030 适配及 PDF 页码恢复。正式包排除测试快捷入口、测试图书与测试 CA。
